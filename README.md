# Протоколирование совещаний — трек 8

Проект хакатона: MP3 → транскрипт → поручения → DOCX. План: [docs/PLAN.md](docs/PLAN.md).

## Текущее состояние

Утверждены план и стек. Начат этап 1; приложение, команды запуска и scripts/check.sh пока не реализованы. Готовность не заявляется.

Первым путём запуска будут обычные команды uv для воспроизведения заранее вычисленных результатов двух MP3 без Docker и GPU (**не проверка моделей**). Вторым — docker compose на GPU для реального распознавания и извлечения поручений.

## Данные

В data/test находятся kz_01.m4a (казахский) и mix_01.m4a (смешанная речь), предоставленные пользователем, и соответствующие *.reference.md. Тексты — сценарии с ожидаемыми поручениями, на слух не сверены; они пока не являются эталоном WER. Голос один, диаризация на них не оценивается.

## Технологии и ограничения

Утверждены Python 3.11/uv, FastAPI, faster-whisper large-v3, SeamlessM4T-v2-large, SpeechBrain ECAPA, self-hosted Qwen/vLLM, PydanticAI и python-docx. Совместимость моделей с сервером проверяется. Аудио и текст обрабатываются в контуре заказчика; внешние API обработки запрещены.

Нативных подключений Teams/Zoom/Meet и автоматической рассылки напоминаний не будет в принятом объёме. Экспорт — DOCX. Полные сведения о сторонних компонентах, установка и пример проверки добавляются по мере фактической реализации.
