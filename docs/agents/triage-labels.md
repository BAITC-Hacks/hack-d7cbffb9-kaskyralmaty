# Triage labels

| Роль | Значение Status | Значение |
|---|---|---|
| needs-triage | needs-triage | Нужна оценка владельца |
| needs-info | needs-info | Недостаточно информации |
| ready-for-agent | ready-for-agent | Готово для агента |
| ready-for-human | ready-for-human | Нужна реализация человеком |
| wontfix | wontfix | Выполняться не будет |

Когда навык указывает роль triage, используй соответствующее значение Status. Эта таблица не меняет workflow wayfinder.
