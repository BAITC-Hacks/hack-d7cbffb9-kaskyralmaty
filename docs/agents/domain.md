# Domain docs

## Перед исследованием кода

Прочитай корневой `CONTEXT.md` и относящиеся к задаче ADR из `docs/adr/`. Если появится `CONTEXT-MAP.md`, следуй его ссылкам на контексты и учитывай ADR соответствующих контекстов.

При отсутствии документов продолжай работу. Создавай их через domain-modeling по мере появления согласованных терминов и решений.

## Структура

Single-context: один `CONTEXT.md` в корне, архитектурные решения в `docs/adr/`.

## Терминология и решения

Используй термины из CONTEXT.md в задачах, коде и проверках. Недостающие понятия отмечай для domain-modeling. Противоречие существующему ADR укажи явно с объяснением; пересмотр решения требует отдельного согласования.
